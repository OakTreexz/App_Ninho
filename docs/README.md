# Documentação do Ninho

Esta pasta reúne os documentos do projeto. Organização sugerida:

| Pasta | O que guardar |
|---|---|
| `requisitos/` | Documento de Requisitos (RF e RNF) e Product Backlog |
| `sprints/` | Documento e apresentação de cada Sprint |
| `conteudo-clinico/` | Formulários de origem (PDF) e as fontes usadas |
| `design/` | Esboços e protótipos das telas |

## Antes de publicar um documento

Este repositório é **público**. Antes de adicionar um arquivo aqui, confira se ele não mostra e-mails, telefones, nomes de terceiros ou outros dados pessoais (por exemplo, impressões de e-mail ou prints com cabeçalho). Se mostrar, remova essas partes antes.
